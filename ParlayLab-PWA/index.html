Setup & limitations

Live data connection

This app uses a server-side proxy to The Odds API. The API key is kept in a hosting environment variable, never stored in the browser.

1. Deploy to Vercel. 2. Add ODDS_API_KEY. 3. Open the HTTPS URL on your iPhone. 4. Tap Share → Add to Home Screen.

On Windows, open the same URL in Edge or Chrome and select Install app.

Market coverage

Game moneylines, spreads and totals are loaded through the league odds endpoint. Tap an event to request available player props. Player prop coverage depends on sport, bookmaker and API plan.

Displayed probabilities are market-implied, not independent predictions. The app does not place bets or access your sportsbook account.
